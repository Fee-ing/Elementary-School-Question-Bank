# 三年级数学 智能组卷 · 答案与解析

> 平均难度权重：0.507　|　难度带分布：基础:7 / 中等:9 / 提高:4

## 选择题
1. 【基础 / w=0.25】答案：B
    解析：完整活动应包括估计、测量和计算。只量长不能求面积；周长不能当面积；只记录估计值也没有完成测量活动。
2. 【中等 / w=0.45】答案：733
    解析：541＋192＝733
3. 【中等 / w=0.55】答案：32千克
    解析：平均数一定在最大值和最小值之间，即23~45之间。只有32千克在这个范围内。
4. 【提高 / w=0.85】答案：西北
    解析：原路返回要面向来时的相反方向，东南的相反方向是西北。

## 填空题
5. 【基础 / w=0.25】答案：17人
    解析：51/3=17人。把总数平均分，用除法。
6. 【中等 / w=0.55】答案：28人
    解析：正方形方阵最外层：每边8人，4条边共8x4=32人，但4个角的人被重复计算了一次，所以32-4=28人。
7. 【中等 / w=0.55】答案：82颗
    解析：倒推法：现在有90颗，吃之前有90+12=102颗，妈妈给之前有102-20=82颗。
8. 【基础 / w=0.25】答案：5颗
    解析：20/4=5颗。平均分用除法。
9. 【基础 / w=0.25】答案：138元
    解析：先算总价：13x3=39元，再算找回：177-39=138元。
