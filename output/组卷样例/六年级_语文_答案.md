# 六年级语文 智能组卷 · 答案与解析

> 平均难度权重：0.529　|　难度带分布：基础:9 / 中等:12 / 提高:4

## 选择题
1. 【基础 / w=0.30】答案：孩子在电灯下读书
    解析：他指着插图说，以后也要让孩子们在这样的灯光下学习。
2. 【提高 / w=0.90】答案：欧阳修
    解析：（无解析）
3. 【中等 / w=0.55】答案：书是人类进步的阶梯。
    解析：题干句子将"他"比作"大树"，是暗喻（比喻）。B项将"书"比作"阶梯"，也是暗喻（比喻）。A项是拟人，C项是夸张，D项是反问。
4. 【基础 / w=0.30】答案：眉眼盈盈处
    解析：要问行人去哪里，就是去山水相接、像眉眼那样的地方。不要在盈盈处后面加字。
5. 【基础 / w=0.30】答案：立根原在破岩中
    解析：竹根长在破裂的岩石中。诗中是破岩，不是破崖。
6. 【提高 / w=0.90】答案：拘泥成法、不知变通
    解析：「刻舟求剑」指拘泥成法、不知变通

## 判断题
7. 【提高 / w=0.82】答案：错
    解析：答案是“错”。“嘱咐”侧重交代要做的事，“提醒”侧重让人注意可能忽略的事。句中奶奶交代我出门前带伞，用“嘱咐”能准确表达；换成“提醒”后表达重点有所变化，所以不能说意思完全相同。
8. 【中等 / w=0.55】答案：错
    解析：赠言重在情感真挚，而非字数多少。
9. 【基础 / w=0.25】答案：对
    解析：柳公权是唐代书法家。“颜筋柳骨”中的“柳”指柳公权，“柳骨”概括其书法骨力遒劲、挺劲有力的特点，因此题干说法正确。
10. 【中等 / w=0.55】答案：错
    解析：山郭是指山城、依山的城镇。

## 填空题
11. 【提高 / w=0.95】答案：①人总是要死的，但死的意义有不同。②道理论证（引用论证）。引用司马迁的名言，有力地论证了「死的意义有不同」，使论述更有说服力。③人总会死去，但死的价值和意义不同：有的意义重大（重于泰山），有的微不足道（轻于鸿毛）。④示例：为人民服务就是要把人民的利益放在第一位，全心全意为人民利益而工作、奋斗。
    解析：【解析】体会论证方法。
12. 【中等 / w=0.55】答案：侧面描写
    解析：答案是“侧面描写”。题目限定分析邻居的反应：邻居停下脚步、四处寻找香味，说明粥香吸引了旁人。作者借邻居的反应衬托粥香，而不是直接评价粥香有多浓。
13. 【中等 / w=0.55】答案：蜷缩；搀扶
    解析：答案是“蜷缩；搀扶”。小狗在寒风中把身体弯曲收紧，适合用“蜷缩”；小明扶着老人过门槛，适合用“搀扶”。两个词表示不同动作，不能互换。
14. 【中等 / w=0.55】答案：团聚
    解析：答案是“团聚”。题目给出的证据是家人围坐在一起庆祝，直接体现团聚情境；“团团圆圆”表达团聚愿望。“年年有余”常借鱼与余谐音表达富足愿望，不是由家人团聚这一线索直接说明的。
15. 【基础 / w=0.38】答案：行为、语言或处境
    解析：答案是“行为、语言或处境”。人物品质配对要先从材料中找人物做了什么、说了什么或面对什么情境，再选择最能概括这些证据的品质；只凭姓名或印象作答，缺少材料依据。
16. 【中等 / w=0.55】答案：《古诗十九首》
    解析：《迢迢牵牛星》是《古诗十九首》中的一首，作者不详。“纤纤擢素手”是该诗中的诗句，因此应按作品集名称作答，不应误填韩翃或王建。
17. 【中等 / w=0.55】答案：……
    解析：答案是省略号“……”。题目说明花卉还没有列完，因此用省略号表示列举未尽；省略号放在句末时已能表示停顿，不再加句号。
18. 【基础 / w=0.38】答案：失望
    解析：答案是“失望”。小明原本期待和家人去公园，后来计划取消；题目限定从“期待”或“失望”中填写，期待落空后相应的心情是失望。

## 其他
19. 【基础 / w=0.38】答案：我们的,时间,在淘气的,怀里,跳动
    解析：运用拟人手法，将时间比作淘气的孩子在跳动。
20. 【基础 / w=0.38】答案：锅里,红红的豆子,像是,无数只,小眼睛
    解析：根据文意和比喻句修饰关系排列。
21. 【基础 / w=0.38】答案：父亲,在法庭上,显得,十分,安定
    解析：语序逻辑：人物+环境+动作+程度+状态。
22. 【中等 / w=0.55】答案：李大钊,是,坚贞不屈的,革命者,的一座,丰碑
    解析：通过比喻评价人物品质。
23. 【中等 / w=0.55】答案：赞扬了,桑娜和渔夫,美好的,善良的,心灵
    解析：这是本课的中心思想句。
24. 【中等 / w=0.55】答案：在生活中,知音,总是,难寻
    解析：语义连贯的叙述句。

    解析：这是全文的结论句，逻辑连贯。
